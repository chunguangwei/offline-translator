# 译人 iOS V1（翻译先行）— 真机验收步骤

> 2026-06-11。模拟器上 UI 冒烟已通过（Claude 本机 Xcode 26.5 自验）。
> 真机需要你的 Apple ID 签名（免费账号即可，7 天有效期，过期重装）。

## 一次性准备

1. 打开工程：
   ```bash
   cd "ios" && xcodegen generate && open Yiren.xcodeproj
   ```
   （改过 `project.yml` 或拉新代码后重跑 `xcodegen generate` 即可，工程文件不入库。）
2. Xcode 里选中 Yiren target → **Signing & Capabilities**：
   - Team 选你的 **Personal Team**（登录 Apple ID 即出现）
   - Bundle Identifier 若提示被占用，改成带你名字的，如 `com.weichunguang.yiren`
3. iPhone 用线连 Mac，首次需在手机上「信任此电脑」+
   设置 → 隐私与安全性 → 开发者模式 → 打开。

## 验收流程（产品决策 2026-06-11：模型不随包，用户应用内自行下载）

1. Xcode 顶部设备选你的 iPhone → **⌘R** 运行（包体 ~10MB，秒装）。
2. 首启 → 翻译页出现「还没有可用的模型」横幅 → 点「去下载」。
3. 模型页下载 **Gemma 4 E2B**（2.6GB，建议 Wi-Fi；国内镜像优先、官方自动兜底）。
4. 下载完自动启用 → 返回翻译页（横幅消失）。
5. 输入「你好，世界」→ 点「翻译」：
   - 首次显示「正在加载模型，请稍等…」（真机预计 10–60 秒）
   - 随后译文**流式**出现，且只输出一种目标语言
6. 点「停止」能中断；上下互换按钮能换方向（English→中文也试一句）。

> **开发提示**：把 `.litertlm` 放进 `ios/BundledModels/`（gitignored）再构建，
> 模型会随包安装、装上即用——纯开发期便利开关，正式分发不带。
>
> **iPhone 13（4GB 内存）**：工程已带 `increased-memory-limit` entitlement。
> 加载模型若仍闪退/被杀，把现象告诉 Claude。

## 已知约束（V1）

- 免费账号签名 **7 天过期**，过期后 app 打不开，重新 ⌘R 装一次即可（模型不丢）。
- V1 仅文本翻译；语音 / 图片问答 / 会话 / 历史 / 启动页在后续阶段对齐 Android。
- 建议 6GB RAM 设备（iPhone 13 Pro / 14 Pro 及之后）；不足可能加载失败或被系统杀。
